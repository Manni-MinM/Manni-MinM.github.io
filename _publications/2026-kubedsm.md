KubeDSM is a Kubernetes-based framework for scheduling and migrating workloads across cloud-assisted edge clusters. Unlike Kubernetes' default scheduler, it schedules in batches to minimize resource fragmentation, and it uses live migration (intra-edge, edge-to-cloud, and cloud-to-edge) to keep latency-sensitive workloads on edge resources when capacity allows.
